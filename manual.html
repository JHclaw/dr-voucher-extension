DR전표 자동입력 사용설명서

연세대학교 미래캠퍼스 재무팀 · 확장 프로그램 v0.4.3 · 2026.10

엑셀에 정리한 매출/수입 내역으로 행정정보시스템의 [매출/수입] 세금계산서/계산서/기타[DR] 화면을 자동 입력하고, 임시전표까지 만들어 주는 크롬/엣지 확장 프로그램입니다.

엑셀 불러오기→DR 화면 자동 입력→행 선택 · 결재문서작성 · 예→결재문서 창 닫기→안내메시지 확인→다음 건
기본 규칙: 계산서 1건 = 엑셀 1줄 = 계정 1개 = DR전표 1건
계산서 하나에 계정을 2개 이상 쓰지 않습니다. 계정이 다르면 계산서(엑셀 줄)를 나눠서 작성하세요.

1건당 약 20~30초가 걸립니다. 150건이면 대략 1시간~1시간 15분 정도입니다.

  • 1. 설치하기 (처음 한 번)
  • 2. 팝업 허용 설정 (처음 한 번)
  • 3. 엑셀 작성하기
  • 4. 실행하기
  • 5. 결과 확인하기
  • 6. 문제가 생겼을 때
  • 7. 새 버전으로 업데이트하기

1. 설치하기 (처음 한 번)

이 확장 프로그램은 웹스토어가 아니라 폴더에서 직접 설치합니다. 크롬과 엣지 모두 같은 방식입니다.

1-1. 프로그램 폴더 준비

  1. dr-voucher-extension 폴더를 지우거나 옮기지 않을 위치에 둡니다. 예: 문서\브라우저확장\dr-voucher-extension
    zip 파일로 받았다면 먼저 압축을 풉니다.
  2. 폴더를 열었을 때 manifest.json 파일이 바로 보여야 합니다. (폴더 안에 같은 이름의 폴더가 한 번 더 있다면 그 안쪽 폴더를 사용)
설치 후에 폴더를 지우거나 옮기면 확장 프로그램이 작동하지 않습니다. 폴더를 옮겼다면 아래 설치 과정을 다시 하세요.

1-2. 브라우저에 설치

②오른쪽 위 개발자 모드 스위치 켜기왼쪽 메뉴 아래쪽 개발자 모드 스위치 켜기
③왼쪽 위 압축해제된 확장 프로그램을 로드합니다 클릭

⑤목록에 DR전표 자동입력 (연세대 미래캠퍼스 재무팀)이 나타나면 설치 완료입니다.
빨간 오류 버튼이 보이면 폴더를 잘못 고른 것이니 삭제 후 다시 설치하세요.

1-3. 툴바에 아이콘 고정 (권장)

  1. 주소창 오른쪽의 퍼즐 조각 모양(확장 프로그램) 아이콘을 클릭합니다.
  2. DR전표 자동입력 옆의 핀(📌) 아이콘을 눌러 툴바에 고정합니다. (아이콘은 "D" 글자로 표시됩니다)
브라우저를 켤 때 "개발자 모드 확장 프로그램을 사용 중지하세요" 같은 안내가 뜰 수 있습니다. 이 확장은 직접 설치한 것이므로 사용 중지하지 말고 창을 닫으면 됩니다.

2. 팝업 허용 설정 (처음 한 번)

임시전표를 만들 때 [결재문서작성]을 누르면 결재문서(그룹웨어) 창이 팝업으로 뜹니다. 사람이 아니라 프로그램이 버튼을 누르면 브라우저가 이 팝업을 차단할 수 있어서, 연세대 사이트의 팝업을 미리 허용해 둬야 합니다.

순서크롬엣지
①주소창에 chrome://settings/content/popups 입력주소창에 edge://settings/content/popups 입력
②팝업 전송 및 리디렉션 사용이 허용됨 옆 추가허용 옆 추가
③[*.]yonsei.ac.kr 입력 후 추가 (연세대 하위 사이트 전체 허용)

위 방법이 안 되면 https://yep.yonsei.ac.kr:50001, https://yserp.yonsei.ac.kr:8443 두 개를 각각 추가하세요.

3. 엑셀 작성하기

함께 드리는 DR전표_입력양식.xlsx의 [입력] 시트에 작성합니다. 머리글(1행)은 바꾸지 마세요.

3-1. 기본 규칙

  • 한 줄 = 계산서 1건 = DR전표 1건입니다. 계산서 1건당 계정(계정사유)은 1개만 씁니다.
  • 문서번호는 줄마다 달라야 합니다. 같은 번호가 두 줄 이상이면 입력오류로 표시하고 그 줄들은 처리하지 않습니다.
  • 문서번호는 아무 값이나 괜찮습니다(1, 2, 3… 또는 관리번호). 단, "예시"로 시작하는 번호와 빈 칸은 무시합니다.
  • [금액]은 비워두면 [총금액]과 같은 값이 들어갑니다. 값을 넣었는데 총금액과 다르면 "주의"로 알려줍니다.

3-2. 항목 설명

항목필수설명

잘못된 예: 한 업체에 공간사용료와 임대료를 같이 청구하더라도, 같은 문서번호로 두 줄을 쓰면 안 됩니다. 계산서를 2건으로 나눠 문서번호 1, 2로 각각 작성하세요.

4. 실행하기

  1. 브라우저에서 연세대학교 행정정보시스템(포털)에 로그인합니다. DR 화면은 열지 않아도 프로그램이 자동으로 엽니다.
    설치나 업데이트 직후 처음이라면 포털 탭을 F5로 한 번 새로고침하세요.
  2. 툴바의 DR전표 자동입력 아이콘을 누르면 오른쪽에 사이드 패널이 열립니다.
  3. 파일 선택으로 작성한 엑셀을 고릅니다.
    • 입력값 검사 통과: 바로 진행 가능
    • 입력오류 N건: 표의 메시지를 보고 엑셀을 고쳐 다시 불러오세요. 그대로 시작하면 오류 건은 건너뜁니다.
    • 주의: 금액과 총금액이 다른 경우 등. 진행은 되지만 확인하세요.
  4. 모드를 고릅니다.
    • 임시전표 자동생성 (기본): 입력 → 행 체크 → 결재문서작성 → 예 → 결재문서 창 닫기 → 안내메시지 확인까지 자동
    • 입력만: 화면 입력까지만 하고 멈춥니다. 직접 확인·처리한 뒤 화면이 비워지면 다음 건을 입력합니다.
  5. 이번에 처리할 건수를 정합니다. 처음에는 1~3건으로 시험해 보고, 결과를 확인한 뒤 늘리세요.
  6. 시작을 누릅니다. 멈추려면 중지 (지금 하던 건이 끝나면 멈춤).
실행 중 주의사항
  • 포털 화면을 클릭하거나 입력하지 마세요. 자동 입력이 꼬일 수 있습니다.
  • 포털 탭을 다른 탭으로 바꾸거나 창을 최소화하면 느려질 수 있습니다. 다른 일은 별도의 브라우저 창에서 하세요.
  • 건수가 많으면 PC가 절전 모드로 들어가지 않게 해 주세요.
  • 포털 로그인이 만료되면 멈춥니다. 다시 로그인한 뒤 시작을 누르면 남은 건부터 이어서 합니다.
이어서 하기: 프로그램은 완료된 전표를 기억합니다. 엑셀을 고쳐 저장하거나 패널을 닫았다 다시 열어도, 같은 엑셀을 불러와 시작을 누르면 완료된 건은 건너뛰고 남은 건만 처리합니다. (전표 내용 기준으로 기억하며, 이 PC의 이 브라우저에만 저장됩니다)

5-2. 결과 엑셀 저장

결과 엑셀 저장을 누르면 원래 엑셀 내용 오른쪽에 처리결과 · 임시전표번호 · 처리메시지 · 그룹웨어문서ID · 처리시각과 소요시간(준비 · 입력 · 생성 · 총소요(초), 입력 단계별 · 생성 단계별 시간)이 붙은 파일이 다운로드 폴더에 저장됩니다.

로그 창 오른쪽 로그 저장을 누르면 화면의 로그를 txt 파일로 저장합니다. 로그에는 건마다 입력 단계시간(부서·기본정보·거래처·계정행·청구계좌)과 생성 단계시간(작성클릭→확인창, 예→안내메시지, 메시지→확인클릭 등)이 남습니다. 패널을 닫으면 로그가 사라지므로 필요하면 먼저 저장하세요.

5-3. 시스템에서 확인

포털 [재무회계 > 일반조회 > 전표 통합 관리]에서 전표유형 DR로 조회하면 만들어진 임시전표를 볼 수 있습니다. 처음 몇 건은 꼭 금액·적요·거래처가 맞는지 확인하세요.

6. 문제가 생겼을 때

증상해결 방법
[시작] 버튼이 회색(비활성)읽힌 전표가 0건입니다. 문서번호가 비어 있거나 "예시"로 시작하지 않는지 확인하세요. 실행 중일 때도 비활성입니다.
"문서번호 'N'가 엑셀 N, N행에 중복됨"계산서 1건에는 계정 1개만 씁니다. 줄마다 다른 문서번호를 주거나, 계정이 여러 개면 계산서를 나눠 작성하세요.
"DR 입력 화면을 찾지 못했습니다"포털에 로그인되어 있는지 확인하고, 포털 탭을 F5로 새로고침한 뒤 다시 시작하세요.
"결재문서 창도 안내메시지도 없음"팝업이 차단된 경우가 많습니다. 주소창 오른쪽에 팝업 차단 아이콘이 있는지 보고, 2. 팝업 허용 설정을 다시 확인하세요.
"검색 목록에서 찾지 못함" (계정과목·자금·청구계좌)엑셀의 코드가 검색창 목록에 없는 값입니다. 메시지에 나온 목록을 참고해 엑셀을 고치세요. 비워두면 후보가 1개일 때 자동 선택됩니다.
"부서 1234: 검색 결과 없음 / 목록에서 찾지 못함"엑셀의 부서코드가 부서 검색창에 없는 값입니다. 화면의 부서 옆 돋보기로 코드를 확인해 고치세요.
"자금이 'X'로 바뀜" / "자금: 검색 목록에서 찾지 못함"자금 목록은 부서에 따라 다릅니다. 부서코드와 자금이 서로 맞는지 확인하세요.
"검색 결과가 여러 개라 자동 선택 안 됨"청구계좌·계정과목·자금을 엑셀에 직접 입력하세요.

7. 새 버전으로 업데이트하기

  1. 새로 받은 파일을 기존 dr-voucher-extension 폴더에 덮어쓰기합니다.
  2. chrome://extensions (엣지: edge://extensions)에서 DR전표 자동입력의 새로고침(↻) 버튼을 누릅니다.
  3. 열려 있던 사이드 패널을 닫았다가 다시 열고, 포털 탭을 F5로 새로고침합니다.

현재 버전은 사이드 패널 제목 옆(예: v0.4.3)에서 확인할 수 있습니다.
